# PosterCut (Mosaika for iOS)

Native SwiftUI iOS 26 Liquid Glass multi-page poster & study sheet studio.

## Highlights
- **Lossless UHD Sheet Slicing**: Export crisp multi-page PDFs (uncompressed Flate/PNG streams) or individual lossless PNG tiles at 150 / 300 / 600 DPI.
- **100% Vector Halftone Posters**: Circles, B&W, Squares, Diamonds, and Engraved Lines rendered seamlessly across sheet seams with 18 quick palettes.
- **Built-in Print Preview & AirPrint**: Inspect every cut sheet with pinch-to-zoom and filmstrip navigation, share directly to WhatsApp / AirDrop / Files, or print at 1:1 millimeter scale via AirPrint.
- **Interactive Canvas**: Poster-First real-world scale reference (180 cm person -> 210 cm doorway & sofa -> 6 m house), tap-to-skip tiles, and interactive corner crop.
- **Native iOS 26 Liquid Glass**: Layered `.icon` app icon (Light, Dark & Tinted), subtle customizable glass themes, Light/Dark/System modes, and strict localization in 15 languages.
- **100% On-Device**: Zero uploads, zero servers, zero tracking.

## Build via GitHub Actions (Xcode 27)
Push to `main` (or trigger `Build PosterCut iOS (.ipa)` manually) to produce `PosterCut-Unsigned.ipa` ready for sideloading via AltKeeper / SideStore.
